HOW TO READ THESE RESULTS
Evidence with its limits

      

        
The four TYM classifiers learn segment types and temporal relations from a parallel English and Romanian story. Ro-TimeBank supplies six ISO-TimeML tasks, each with a lexical baseline and a structured text variant. Their label families describe different tasks; model comparisons are informational.

        
These lexical baselines can miss explicit cues and return plausible but incorrect labels. A prediction snapshot records model behavior. It provides no estimate of accuracy on independent narratives.

        
For TimeBank tasks, mark the intended mention with [TARGET] and [/TARGET]. Relation predictions follow the source and target order shown in the example. The tools score supplied text and do not automatically annotate an entire document.

Compare algorithms

Neural experiments train small models from scratch. Book passages are unlabeled, so their clustering and reconstruction results have no semantic accuracy score. Timing is a local batched measurement, not the response time of this website. Memory values cover shared benchmark processes; storage sizes refer only to exported artifacts.
