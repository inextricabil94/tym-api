# Separate TS/TT Viewer and Language Buttons: 20 October 2026

## Changes

- The text-order TS row is rendered in a separate, named overview above the TT display. Each has its own keyboard-focusable scroll container. TT paging, grouping, filtering, fit and zoom do not move or hide the overview, including when no tracks match a filter.
- TS stays at native scale with horizontal scrolling. The TT viewer starts its tracks at its own top margin, without duplicating the overview. The legend stays with TT. The complete SVG download still contains both TS and every TT, regardless of the current page/filter; cached API responses are not mutated.
- Interface language is selected through native **English** and **Română** buttons, with self-hosted flag icons, visible labels, keyboard activation and `aria-pressed` state. The interface dropdown was removed. Browser/default language, saved preference and cross-tab synchronization are retained. Text/NLP language remains a separate select field.
- Flag assets are unmodified flag-icons v7.5.0 GB/RO SVGs with their original MIT license, served from the same UI origin. No runtime icon library or third-party image request was added.

This is a UI-only increment. NLP, graph generation, quotas, source access, account configuration and the existing API image remain unchanged. No account database or paid resource was created.
