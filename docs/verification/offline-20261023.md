# Offline Cache Publication: 23 October 2026

## Published

The browser saves public book/chapter metadata and successful generated diagrams
in bounded IndexedDB storage. Saved diagrams are filtered by API and exact window
resolution. A versioned service worker caches only the public application shell,
self-hosted React, fonts, flags and example images. No offline NLP is claimed.
Saved diagrams / Cached TT density use horizontally aligned label, input and
status rows, including narrow screens and enlarged bilingual labels.

The API includes the tested private SQLite response-cache implementation, but
**production database caching remains disabled**: no persistent volume is mounted
and `TYM_DIAGRAM_CACHE_PATH` is unset. No database, volume or paid service was
provisioned. Public source reading and disabled live accounts are unchanged.
Generated cached responses can contain substantial excerpts; raw source-reader
responses, original input drafts, credentials and IP-bound sessions are not saved.
See [cache behavior and limits](../offline-caching.md).

## Checks

- API/checker and UI Release builds passed without warnings/errors. All 51 Node
  tests passed. SQLite persistence/expiry/eviction and namespace checks passed;
  the isolated HTTP test verified hits after an API restart, nine identical
  progressive views, fresh session IDs and the exposed cache header.
- Real IndexedDB and service-worker tests passed locally and on both live UI
  hosts: offline reload/reopen, no repeat generation, metadata-only catalog,
  protected-result export policy, exact resolution, clear, concurrent writers,
  and exclusion of restricted-book results and source-reader responses.
- Live verification exposed a timing race where repeat generation could replace
  completed live views with an older saved bundle. The corrected UI prefers the
  matching live bundle and flushes it before reuse without restarting warming.
  A deterministic older-snapshot regression passed locally and on both hosts.
- The bilingual browser suite passed, including 20 header-alignment cases,
  20 selector-alignment cases and six enlarged 26-pixel selector cases across
  English/Romanian and widths 320/390/768/1440/1920. The 36-case segmentation
  presentation suite passed locally and on the final static website.
- A real authored Romanian perceptron request through the static UI produced
  five events and four TS, warmed all ten densities, preserved exact marked
  source and reported `X-TYM-Cache: DISABLED`. Repeat generation made no second
  POST; all ten views reopened after an actual offline reload. Browser errors:
  zero. Two actual generation requests were used during this release, including
  the initial timing-race investigation; fixture suites use no live quota.
- All 36 public UI files match local SHA-256 hashes on both hosts. Both configs
  retain the intended API URL and zero private local examples. Static files have
  no-cache metadata. The new three-page improvements PDF matches local bytes;
  all pages were rendered and reviewed, with zero out-of-page characters. The
  existing 20 October audit PDF checksum is unchanged.
- All sixteen books retain source checksums, character counts and section counts.
  Catalog summary SHA-256 before/after:
  `9F26499CA89B5986DF9E6970061E84B96180319B83473F593A4699A918B5A81C`.
  No books, databases, mail or credentials entered Git or static assets. The
  library was copied between existing private registry layers.

These results are engineering regression evidence, not NLP accuracy scores.
