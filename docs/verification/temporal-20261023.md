# Temporal Segmentation Publication: 23 October 2026

## Published Behavior

The v0.9 API groups extracted events into retained temporal developments rather
than treating punctuation, changed entity lists, locations or paragraphs as TS
boundaries. Supported time/context shifts, perspectives and explicit interaction
cues delimit developments. A TS can cover many sentences and paragraphs.
Rules and both ML.NET algorithms remain selectable; their seed-trained, guarded
predictions are not a corpus-validated automatic implementation of the full paper.

The bilingual source inspector displays temporal frame, symbolic time reference,
boundary basis and raw model score. Clients require
`segmentation.unit = temporal_development`. API/browser namespaces and shell
versions exclude incompatible older results. See the
[changes report](../research/TYM_Temporal_Segmentation_Changes_20261023.md).
