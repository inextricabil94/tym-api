# Cached TT Density Views

One UI generation requests the chosen density plus presets 1, 10, 20, 30, 40, 50, 60, 70, 80, 90 and 100. The viewer's Cached TT density menu switches views without network calls or additional daily permits. A requested nonpreset density also remains selectable. The input slider selects a cached preset immediately; a new, uncached slider value takes effect on another generation.

The API opt-in is `options.cache_track_densities: true` on `POST /v1/diagrams`; default is false for existing clients. Extraction, classifications, reference highlighting and TimeML are computed once. Track placement, endpoints, relations, boundaries, statistics, SVG and XML are built from that shared analysis. Identical partitions reuse the base response or a shared alternate view. Source events, entity mentions and segment texts are not repeated in every alternate JSON view. SVG/XML endpoints return their selected single view rather than computing a bundle.

The response's `density_cache.options` maps each preset to `base` or a key in `density_cache.views`. Alternate views carry tracks, segment placements keyed by TS ID, topology, analysis, warnings, render and XML. The UI reconstructs the active response from shared annotations plus that view. SVG, JSON and XML exports follow the selected density, not the originally requested one. Track filters, pagination and balanced display groups use its current tracks.

The cache is scoped to the current result in page memory. It is not stored in local storage or shared between users. Text/chapter, language, API URL, width or highlight changes invalidate it. Stale responses from an earlier input context are ignored. A page refresh discards it. Generation still uses the existing five-per-IP daily policy; the whole bundle is one request/permit. Responses use `no-store` and support HTTP compression. Long inputs need more rendering time and memory than a single view; this does not cache analyses across chapters or process restarts.

Local verification on 19 October 2026 compared all eleven cached presets with independent English and Romanian generations (22 topology/SVG/XML/statistics comparisons). Existing 202 density and 19 anaphora cases passed. Twenty-four Node tests covered cache reconstruction, deduplication, legacy responses, chapter splitting and display groups. Browser verification switched all presets plus requested density 37, checked every SVG/JSON/XML export, confirmed zero switch/export requests, tested widths 320-1920, and confirmed the bundle consumes exactly one daily permit. A 35-segment fixture required six unique alternate payloads rather than eleven copies. These are implementation checks, not NLP accuracy measurements.
